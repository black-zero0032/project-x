# Aturan proyek Project X
Panggil pengguna Zephyr. Baca docs/TEAM_HANDOFF.md dan panduan HQ yang ditautkan.
Sepakati kebutuhan baru dengan Zephyr sebelum implementasi. Kerjakan hanya lingkup yang disetujui.
Kode, tes dan dokumentasi produk berada di repo ini. Catat setiap pekerjaan, bukti uji, keterbatasan dan langkah lanjut di docs.
Jangan menyalin sumber produk ke repo HQ. Jangan menimpa perubahan pengguna.
Ikuti panduan BMAD/ECC/spesialis dari repo HQ bila tersedia; jika akses kurang, laporkan.
Publikasi dan biaya baru memerlukan izin yang relevan. Dokumentasi tidak memberi akses runtime otomatis.

Operasional produk tidak wajib melalui HQ. Baca pemetaan pelaksana lokal dan aturan koordinasi dalam docs/TEAM_HANDOFF.md. Gunakan chat lokal produk atau delegasi resmi yang diotorisasi; jangan menyamakan akses GitHub dengan akses runtime. Semua kode tetap di folder kanonis produk, bukan folder administratif chat.
